# Historical Eliot prototype

This directory preserves the previous Gemini/MongoDB implementation, experimental
agent modules, entrypoints, deployment scripts and documentation for reference.
The supported application is `../eliot_app`; install it with `../install.sh`.
Nothing here is installed or executed by the remastered installer or wheel.

The archived installers can change system services, global Python packages and
configuration. They describe the old prototype and are not supported setup paths.
Do not use them to install the remaster. Legacy Python modules have selected
regression fixes, but have not been migrated to the current runtime or validated
as a complete application. Their internal paths and original documentation may
refer to the old repository layout.
